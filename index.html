疊圖分析

載入

左邊載入正面、右邊載入背面。需要的話先按左右鏡像，讓兩邊的穿孔方位一致，再開始分析。分析會用三個圓穿孔對位，只把對得上的 bump 高度相加。

疊圖結果

量階高：在任一張圖拖一條線，三張圖會畫上同一條線。每張圖下方各自有剖面，可在剖面上點兩個點量階高。線段和階高標記旁的小叉可移除該項。

關於與說明

分析分頁處理單張高度圖，格式與點雲檢視器相同。流程是刪除雜點、找出每一顆 Bump、取出周圍的 Donut 基底，再去掉晶圓翹曲，得到各顆的真實高度與共面性。

五個步驟

  • 載入：一次開啟一張高度圖，也可以把檔案拖進畫面。
  • 刪除雜點：在高度分布上拖左右界線，留下包含 Bump 的高度；也可按自動，依分布帶入一組界線。界線外的高度在後續步驟視為無效，原始檔案不會被改寫。
  • 識別 Bump：以上一步留下的連通輪廓為準。外接矩形的長與寬都落在設定範圍內就保留，方向不拘，其餘視為無效。隔離距離要求輪廓與其他有效像素分開；雜點上限可讓隔離時略過太小的鄰近輪廓。設為 0 表示不做該項檢查。
  • 基底對照：Donut 從 Bump 輪廓往外量，寬度以 pixel 計，高度取自載入時的原圖。畫面左邊是 Bump，右邊是基底。離群過濾可選標準差、RANSAC 或不過濾，用來決定哪些基底點參與後面的曲面擬合。
  • 計算結果：用留下的基底點擬合一張全域二次曲面，再計算每一顆 Bump 的高度。至少需要 3 顆 Bump，過濾後的基底點至少 6 點。

每一顆的數值

  • ΔZ：頂點 Z 減去全域曲面在該頂點的高度。
  • H：去翹曲後的真實高度，等於 ΔZ × cos(傾角)。
  • 球高：頂點 Z 減去該顆 Donut 的中位 Z。
  • 球高 − ΔZ：球高與 ΔZ 的差。正值表示曲面高於旁邊的 Donut。
  • 共面性 PV：各顆 H 扣掉最佳平面後，殘差的最大值減最小值。側欄同時列出平均真實高度、最大傾角、參與擬合的基底點數與 Bump 數。傾角是全域曲面在該顆頂點的傾斜角度，殘差是該顆 H 相對最佳平面的偏差。

看結果與量測

計算完成後可切換總圖、H 圖、球高圖與 Donut 中位數圖。後三張以圓點表示每一顆，可用分布圖的左右界線篩選，並標記最高與最低。點表格一列會把圖移到該顆 Bump，結果可輸出 CSV。圖上可平移、讀數值、量距離與量階高；剖面沿目前畫面上看得到的高度取值。右鍵可把整張圖或目前視野存成 BCRF 或 ASC。

關於與說明

疊圖分析把同一片的正面與背面高度圖對在一起，只把對得上的 Bump 高度相加。格式與點雲檢視器相同，兩張圖的像素數可以不同。

怎麼對位

  • 左邊載入正面、右邊載入背面，可拖曳檔案，或按該圖標題欄的資料夾開啟。標題欄的垃圾桶只清除這一側，上方垃圾桶一次清除兩邊。圖上的 Bump 需要是分開的有效區域，並要有可辨認的圓形穿孔。
  • 若左右方向相反，先按左右鏡像，讓兩邊的穿孔方位一致。鏡像只用於這次分析，不改原始檔案。
  • 開始分析後，各自把連在一起的有效像素當成一顆 Bump，面積明顯偏小的會略過，並找出最大的三個圓穿孔。再用這三個孔做旋轉與平移對位，不縮放，也不另外鏡像。孔對得上但 Bump 重疊太低時，請先鏡像再分析。
  • 對位後，把距離夠近的正面與背面 Bump 配成唯一的一對。相加高度是兩顆 Bump 有效像素的平均 Z 相加。對不上的顆數會分開統計。

三張圖與統計

結果有三張同步的圖：正面、對齊到正面座標的背面，以及相加圖。相加圖只畫出配對成功的 Bump。三張圖都以圓點表示每一顆，顏色對應該顆高度；相加圖的顏色是相加高度。側欄列出配對顆數、只有正面、只有背面、正面與背面顆數、旋轉角、孔心殘差、Bump 重疊率、配對距離、節距、圓盤直徑，以及相加高度的中位數、5%–95% 與最小／最大。

量測

三張圖的平移、縮放、距離測量與剖面線同步。在任一張圖拖一條剖面，三張圖會畫上同一條線；每張圖下方的剖面可各自點兩個點量階高。線段和階高標記旁的小叉可移除該項。可標記最高與最低，並調整圓點大小。

λs 濾波說明

λs 是什麼？

λs（S-filter nesting index／短波截止）用來去除量測噪聲與微粗糙。比 λs 短的起伏被低通拿掉，比 λs 長的成分保留為 primary surface，再進行去趨勢與（可選）λc 濾波。

本軟體如何定義與計算

  1. 若 λs > 0，先對評估區域做高斯 S 濾波（低通），輸出即 primary surface。
  2. 再對 primary surface 做去趨勢（減平均／平面／二次曲面等）。
  3. 高斯尺度與 λc 相同：α = √(ln 2 / π)，σ = α · λs / √(2π)；核支撐內若有缺值（NaN），該點輸出 NaN。
  4. λs = 0（關閉）時跳過短波濾波，直接對原始高度去趨勢。

單位與選值建議

  1. λs 單位與資料的 X／Y 長度相同（見檔案資訊中的 x-length、y-length）。
  2. 建議至少約 3～5 個像素間距；遠小於 1 個像素時幾乎無去噪效果。
  3. 若同時開啟 λc，應維持 λs < λc，否則保留帶寬不合理。

注意事項

此為瀏覽器端實作的區域高斯 S 濾波低通，便於相對比較與短波噪聲抑制；若需與特定儀器報表完全一致，請確認對方採用的濾波標準與 λs 定義後再對照。

λc 濾波說明

λc 是什麼？

λc（截止波長／L-filter nesting index）用來區分「粗糙度」與「波紋／長波長起伏」。比 λc 長的起伏視為波紋（被拿掉），比 λc 短的起伏保留為粗糙度，再計算 Sa、Sq 等參數。

本軟體如何定義與計算

  1. 可選先做 λs S 濾波（低通），再對評估區域做去趨勢（減平均／平面／二次曲面等），得到殘差面。
  2. 若 λc > 0，對殘差面做高斯 L 濾波（低通），再取高通：粗糙度 = 殘差 − 低通結果。核支撐內若有缺值（NaN），該點輸出 NaN 並自統計排除，不重正規化權重。
  3. 高斯尺度採 ISO 16610：α = √(ln 2 / π)，常態核 σ = α · λc / √(2π)（截止波長處約 50% 傳輸）；再依像素間距 dx、dy 換成像素核寬，做可分離 2D 卷積。
  4. λc = 0（關閉）時不濾波，直接在去趨勢後的殘差上計算參數。

單位與選值建議

  1. λc 單位與資料的 X／Y 長度相同（見檔案資訊中的 x-length、y-length）。
  2. 建議至少約數個像素間距；遠小於 1 個像素時，濾波核近乎恒等，高通殘差≈0，Sa 會接近 0。
  3. 可使用下拉預設（長度 ÷ 10ⁿ）。有儀器／客戶規格時，優先使用規格指定的 λc。若同時開啟 λs，應維持 λs < λc。

注意事項

此為瀏覽器端實作的區域高斯 L 濾波高通，便於相對比較；若需與特定儀器報表完全一致，請確認對方採用的濾波標準與 λc 定義後再對照。

λs 濾波說明（輪廓）

λs 是什麼？

λs（S-filter nesting index／短波截止）用來去除量測噪聲與微粗糙。比 λs 短的起伏被低通拿掉，比 λs 長的成分保留為 primary profile，再進行去趨勢與（可選）λc 濾波。意義與表面粗糙度（Sa）相同，但此處作用在剖面線上。

本軟體如何定義與計算

  1. 先沿剖面線從高度圖取樣，得到一維高度序列。
  2. 若 λs > 0，對該序列做一維高斯 S 濾波（低通），輸出即 primary profile。
  3. 再對 primary profile 做去趨勢（減平均／最小平方直線等）。
  4. 高斯尺度與 Sa 相同：α = √(ln 2 / π)，σ = α · λs / √(2π)；再依沿線取樣間距換成像素核寬。核支撐內若有缺值（NaN），該點輸出 NaN。
  5. λs = 0（關閉）時跳過短波濾波，直接對原始剖面去趨勢。

單位與選值建議

  1. λs 單位與資料的 X／Y 長度相同（見檔案資訊中的 x-length、y-length）。
  2. 建議至少約 3～5 個沿線取樣間距；遠小於 1 個取樣點時幾乎無去噪效果。
  3. 若同時開啟 λc，應維持 λs < λc，否則保留帶寬不合理。

注意事項

此為瀏覽器端實作的一維高斯 S 濾波低通，便於相對比較與短波噪聲抑制。概念與 Sa 分頁相同，但濾波維度為剖面而非區域面；若需與特定儀器報表完全一致，請確認對方採用的濾波標準與 λs 定義後再對照。

λc 濾波說明（輪廓）

λc 是什麼？

λc（截止波長／L-filter nesting index）用來區分「粗糙度」與「波紋／長波長起伏」。比 λc 長的起伏視為波紋（被拿掉），比 λc 短的起伏保留為粗糙度，再計算 Ra、Rq 等參數。意義與表面粗糙度（Sa）相同，但此處作用在剖面線上。

本軟體如何定義與計算

  1. 先沿剖面線取樣；可選先做 λs S 濾波（低通），再做去趨勢（減平均／直線等），得到殘差剖面。
  2. 若 λc > 0，對殘差剖面做一維高斯 L 濾波（低通），再取高通：粗糙度 = 殘差 − 低通結果。核支撐內若有缺值（NaN），該點輸出 NaN 並自統計排除，不重正規化權重。
  3. 高斯尺度採 ISO 16610：α = √(ln 2 / π)，常態核 σ = α · λc / √(2π)（截止波長處約 50% 傳輸）；再依沿線取樣間距換成像素核寬，做一維卷積（與 Sa 的可分離 2D 卷積不同）。
  4. 開啟 λc 時，另以 λc 作為取樣長度（sampling length），將評估長度分成數段，對各段計算 Ra／Rq／Rz 等後再平均（ISO 4287 風格）。
  5. λc = 0（關閉）時不濾波，也不分段，直接在整段去趨勢後的剖面上計算參數。

單位與選值建議

  1. λc 單位與資料的 X／Y 長度相同（見檔案資訊中的 x-length、y-length）。
  2. 建議至少約數個沿線取樣間距；遠小於 1 個取樣點時，濾波核近乎恒等，高通殘差≈0，Ra 會接近 0。
  3. 可使用下拉預設（長度 ÷ 10ⁿ）。有儀器／客戶規格時，優先使用規格指定的 λc。若同時開啟 λs，應維持 λs < λc。

注意事項

此為瀏覽器端實作的一維高斯 L 濾波高通，便於相對比較。概念與 Sa 分頁相同，但濾波為剖面一維，且 λc 同時作為取樣長度；若需與特定儀器報表完全一致，請確認對方採用的濾波標準與 λc 定義後再對照。

表面參數說明

計算基礎

下列參數皆在濾波與去趨勢後的殘差面 z(x,y) 上統計（單位與 Z 相同）。本軟體以有效像素離散近似：N 為有效點數，zi 為第 i 點殘差高度。

Sa

算術平均高度：殘差絕對值的平均，最常用的整體粗糙度指標。

Sa ≈ (1/N) · Σ |zi|

越大代表表面整體起伏越大；對極端尖峰不如 Sz／Sp／Sv 敏感。

Sq

均方根高度：殘差平方平均再開根號，類似標準差。

Sq ≈ √[(1/N) · Σ zi²]

對較大偏差比 Sa 更敏感；高斯分布時約 Sq ≈ 1.25 · Sa。

Sp

最大峰高：殘差中最高正值（最高凸起相對基準面的高度）。

Sp = max(zi)

Sv

最大谷深：殘差中最低負值的絕對值（最深凹谷相對基準面的深度）。

Sv = |min(zi)|

Sz

最大高度：最高峰與最深谷的總落差。

Sz = Sp + Sv = max(zi) − min(zi)

對毛刺、凹坑等局部極端值非常敏感，常搭配殘差圖檢查異常點。

Ssk

偏度（skewness）：描述高度分布是否左右對稱。

Ssk ≈ [ (1/N) · Σ zi³ ] / Sq³

≈0 近似對稱；>0 高峰（凸峰）較突出；<0 深谷較突出。平坦或近似零殘差時可能無定義（顯示為 -）。

Sku

峰度（kurtosis）：描述高度分布尖銳／尾部輕重程度。

Sku ≈ [ (1/N) · Σ zi⁴ ] / Sq⁴

常態分布約為 3；>3 表示尖峰／長尾較明顯；<3 表示較平坦。近似零殘差時可能無定義。

參考

定義風格對應 ISO 25178 區域參數。實際數值仍取決於去趨勢與 λs／λc 設定。

輪廓參數說明

計算基礎

下列參數皆在剖面濾波與去趨勢後的粗糙度輪廓 z(s) 上統計（s 為沿線弧長）。本軟體以有效取樣點離散近似：N 為有效點數。若開啟 λc，會以 λc 為取樣長度分段，對各段計算後再平均（Rt、Rsk、Rku 除外，見各項）。

Ra

算術平均粗糙度：輪廓絕對高度的平均，最常用的線粗糙度指標。

Ra ≈ (1/N) · Σ |zi|　（有 λc 時為各取樣段平均）

越大代表輪廓整體起伏越大；對極端尖峰不如 Rz／Rt 敏感。

Rq

均方根粗糙度：輪廓高度平方平均再開根號。

Rq ≈ √[(1/N) · Σ zi²]　（有 λc 時為各取樣段平均）

對較大偏差比 Ra 更敏感；高斯分布時約 Rq ≈ 1.25 · Ra。

Rp

最大峰高：取樣段內最高正值；有 λc 時為各段 Rp 的平均。

Rp = max(zi)　（段內；再開段平均）

Rv

最大谷深：取樣段內最低負值的絕對值；有 λc 時為各段 Rv 的平均。

Rv = |min(zi)|　（段內；再開段平均）

Rz

最大高度（段平均）：各取樣段內（Rp + Rv）再平均。

Rzi = Rpi + Rvi；　Rz = mean(Rzi)

反映典型峰谷落差；比 Rt 較不受單一極端點支配（因分段平均）。

Rt

總高度：整段評估長度上最高峰與最深谷的總落差（不分段平均）。

Rt = max(zi) − min(zi)　（整段評估長度）

對局部極端值最敏感，常用來檢查毛刺或異常凹坑。

Rsk

偏度：輪廓高度分布是否對稱（在整段評估長度上計算）。

Rsk ≈ [ (1/N) · Σ zi³ ] / Rq_eval³

≈0 近似對稱；>0 高峰較突出；<0 深谷較突出。近似零殘差時可能無定義。

Rku

峰度：輪廓高度分布尖銳／尾部輕重程度（在整段評估長度上計算）。

Rku ≈ [ (1/N) · Σ zi⁴ ] / Rq_eval⁴

常態分布約為 3；>3 尖峰／長尾較明顯；<3 較平坦。近似零殘差時可能無定義。

參考

定義風格對應 ISO 4287 輪廓參數。實際數值仍取決於剖面線、去趨勢與 λs／λc 設定。

殘差圖說明

殘差圖是什麼？

殘差圖顯示「去掉整體形狀／傾斜／波紋之後」真正用來計算粗糙度的表面。數字（Sa、Sq、Sz）告訴你「有多粗」；殘差圖告訴你「粗在哪裡、呈現什麼形態」，也可檢查計算結果是否合理。

它怎麼算出來？

  1. 可選先做 λs 短波濾波去除噪聲，再對評估區域去趨勢（減平均／平面／二次曲面等）。
  2. 殘差 = 表面高度 − 擬合基準面。若開啟 λc，會再拿掉長波波紋，只留下粗糙度分量。
  3. Sa、Sq、Sp、Sv、Sz 等參數都是對這張圖上的有效點統計而來。

怎麼看顏色？

  1. 白色：接近基準面，殘差約為 0。
  2. 紅色：高於基準面（凸起、顆粒、毛刺）。
  3. 藍色：低於基準面（凹坑、刮痕、孔洞）。
  4. 顏色越深：偏離基準面越多。色階正負對稱，紅、藍強度可直接比較。
  5. 黑色：無效或缺測點（NaN），不參與統計。

初學者可以這樣觀察

  1. 紅藍均勻、隨機分布：通常是一般微觀粗糙。
  2. 仍有大面積漸層：可能去趨勢不足（例如應改用二次曲面），或還有未去除的波紋。
  3. 明顯條紋或週期圖案：可能來自加工紋路、掃描方向、震動或週期性誤差。
  4. 局部極端紅／藍點：可能是毛刺、刮痕、凹坑或量測異常，會明顯影響 Sp、Sv、Sz。

搭配殘差直方圖

  1. 橫軸中間的 0 是基準面；柱子越靠近 0，多數區域越貼近基準。
  2. 分布越寬：Sa、Sq 通常越大（整體更粗）。
  3. 偏向正值：凸峰較突出，Ssk 可能為正；偏向負值：凹谷較突出，Ssk 可能為負。
  4. 出現長尾或少數極端值：可能有局部缺陷，請對照殘差圖位置檢查。

一句話記住

參數回答「有多粗」；殘差圖回答「粗在哪裡、長什麼樣，以及這次計算是否可信」。

      單向水平校正說明

      功能目的

      只用一個方向去掉整張圖的傾斜。在校正前影像放一條水平或垂直校正線，依線上的高度擬合斜率，再對全圖扣除該方向的傾斜。

      操作流程

      1. 載入高度圖後，點選工具列「單向水平校正」進入此模式。
      2. 點「水平校正線」或「垂直校正線」立刻切換。水平線用來校正左右傾斜，垂直線用來校正上下傾斜。
      3. 拖曳左側校正線到要取樣的位置。系統依該線的高度值擬合斜率，並把校正後的全圖顯示在右側。
      4. 下方折線圖顯示校正線上的高度與擬合直線。可在斜率欄修改數值後按 Enter，或按「重設斜率」回到該線的擬合結果。
      5. 確認結果後按「套用」寫入資料並離開；按「取消」則放棄預覽。

      演算法原理

      1. 取樣：水平校正線取單一列（沿 X），垂直校正線取單一欄（沿 Y）。
      2. 斜率：對線上有效高度做 1D 最小平方擬合 z = k·t + c，t 為相對影像中心的物理距離（mm），k 的單位為 µm/mm。
      3. 全圖套用：只扣除這個方向的傾斜。水平校正線對每個像素扣除 k×(x−中心)×dx；垂直校正線扣除 k×(y−中心)×dy。另一個方向與截距保持不變。

      注意事項

      僅適用於規則網格高度圖；散布點雲不支援。校正線上至少需要 2 個有效點。一次只校正一個方向；若兩個方向都要去除，可分別套用一次水平校正線與一次垂直校正線。

      擇區水平校正說明

      功能目的

      在已知平坦的參考區域框選資料源，以該區擬合傾斜平面後套用到整張圖，避免特徵區或異常點干擾全域水平校正。

      操作流程

      1. 載入高度圖後，點選工具列「擇區水平校正」進入此模式。
      2. 在左側原圖上拖曳框選要作為校正資料源的區域（方形或圓形）。
      3. 系統以資料源擬合平面參數，扣除傾斜後顯示於右側全圖預覽。
      4. 可調整或清除框選後重新計算；確認結果後按「套用」寫入資料並離開。

      演算法原理

      1. 資料源擬合：僅使用框選區內有效像素，以最小平方法擬合平面 z = ax + by + c（座標為實體尺寸）。
      2. 全圖套用：對整張圖每個有效像素扣除傾斜分量 ax + by，保留截距，使數值區間維持接近原始。
      3. 與全域水平校正相同僅去傾斜；差異在於平面參數只由使用者指定的資料源決定。

      注意事項

      僅適用於規則網格高度圖；散布點雲 (.pcd / .txt) 不支援。資料源內至少需要 3 個有效點才能擬合平面。請選擇相對平坦、代表性良好的參考面作為資料源。

      分區水平校正說明

      功能目的

      針對階梯狀或多平台高度圖，自動偵測分割方向與帶數，扣除各帶共用傾斜後將各平台墊高對齊，消除接縫處的高度落差。

      操作流程

      1. 載入高度圖後，點選工具列「分區水平校正」進入此模式。
      2. 進入後不會自動計算。按「自動」偵測分割方向與等份數，或自行設定後即開始計算。完成後會在校正前後影像正中間放上一條剖線；下方折線圖顯示該剖線的高度與各帶斜率。
      3. 可調整「分割方向」「等份數」，或於「斜率微調」修改共用斜率後按 Enter 更新預覽。
      4. 勾選「顯示分割線」可疊加等分邊界；影像與剖面圖支援滾輪縮放、拖曳平移、雙擊還原。
      5. 確認結果後按「套用」寫入資料並離開；按「取消」則放棄預覽、還原原始資料。

      演算法原理

      1. 方向偵測：分別建立水平與垂直方向的邊界能量剖面（相鄰像素高度差與平均高度階梯），比較結構強度後選定分割方向。
      2. 帶數決定：分析平均高度剖面的階梯跳變，在 2～N 等份候選中挑選「帶間變異大、帶內變異小」的最佳等份數。
      3. 邊界位置：採幾何等分（round(b × 軸長 / 帶數)），不做接縫微調，確保各帶寬度均勻且滿足最小間距約束。
      4. 斜率估計：各帶獨立做 1D 線性擬合（z = k·t + c，t 為物理距離 mm），取有效帶斜率的算術平均作為全圖共用 k（µm/mm）。
      5. 扣除傾斜：各帶以帶中心為基準，從每個像素扣除 k × 距離 的傾斜分量，保留各帶截距。
      6. 墊高對齊：計算各帶平均高度，將較低帶整帶加上高度差，對齊至最高帶，使各平台處於同一水平面。

      注意事項

      僅適用於規則網格高度圖；散布點雲 (.pcd / .txt) 不支援。與「全域水平校正」不同，本功能保留各帶截距，專門處理階梯狀多平台資料。

      分區錯位校正說明

      功能目的

      針對多帶拼接高度圖的平面錯位（skew／剪切）。分割方向由使用者選擇；「自動」只偵測該方向的等份數。共用 shift 由使用者設定（預設 0），各帶套用線性剪切後拼回。

      操作流程

      1. 載入高度圖後，點選工具列「分區錯位校正」進入此模式。
      2. 進入後不會自動計算。按「自動」只依目前分割方向偵測等份數，不計算共用 shift；或自行設定分割方向與等份數後即開始計算，並顯示校正前後對照影像。
      3. 可調整「分割方向」「等份數」。左側修改共用 shift，右側可讓各帶再整帶平移相同像素，按 Enter 更新預覽。
      4. 勾選「顯示分割線」可疊加等分邊界；影像支援滾輪縮放、拖曳平移、雙擊還原。
      5. 確認結果後按「套用」寫入資料並離開；按「取消」則放棄預覽、還原原始資料。

      演算法原理

      1. 分割方向由使用者選擇（水平或垂直）。自動不會改寫方向。
      2. 帶數決定：自動只看目前分割方向的接縫能量，在 2～N 等份候選中挑選等分邊界最對齊接縫峰值的帶數（弱接縫會拉低分數，避免過度分割）。
      3. 邊界位置：採幾何等分，與分區水平校正相同，確保各帶寬度均勻。
      4. 共用 shift 由使用者輸入，預設為 0，不會自動估算。
      5. 各帶使用同一個共用 shift，作為該帶剪切從起點到終點的位移量。
      6. Skew 變換：各帶先沿 skew 軸從起點 0 線性漸增至共用 shift，再可加上該帶自己的固定平移（帶內每個像素同向移動相同距離）。正負位移規則相同，超出範圍的兩側都填 NaN。
      7. 拼回：將各帶校正結果寫回完整影像，空缺處以 NaN 填補。

      注意事項

      僅適用於規則網格高度圖；散布點雲 (.pcd / .txt) 不支援。本功能校正平面像素錯位，不改變各帶高度值；與「分區水平校正」（處理高度落差）互補，可視需求分別或依序使用。

      ASCII 文字格式：以 # 開頭的行為標頭，其餘為數值高度矩陣（空白或逗號分隔）。
      .csv
      FSS 區域掃描 CSV：開頭為標題、Signal ID、x_range、y_range，其後為以分號分隔的數值矩陣，NaN 表示無效點。檔案不含單位，載入時需指定。
      .pcd
      Point Cloud Data 標準格式：文字標頭定義欄位與點數，資料區可為 ASCII、binary 或 binary_compressed 編碼的 x、y、z 點雲。
      .txt
      純文字三欄座標：每行 x y z（空白或逗號分隔），# 開頭為註解。適用於匯出的散布點雲。
